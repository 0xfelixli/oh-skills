# Style Presets

Use these presets to stabilize output quality.

## professional-tech (default)

- Palette: deep blue, cyan, neutral gray
- Mood: reliable, sharp, modern
- Elements: abstract geometry, subtle data/tech motifs
- Avoid: neon overload, noisy gradients

## business-clean

- Palette: white, black, muted brand color
- Mood: calm, executive, editorial
- Elements: clean blocks, simple lines, strong spacing
- Avoid: decorative effects and heavy textures

## education-knowledge

- Palette: blue/green with warm accent
- Mood: approachable, clear, structured
- Elements: icon-like shapes, notebook/grid hints
- Avoid: childish cartoon style

## ai-futuristic

- Palette: dark background + bright accents
- Mood: forward-looking, technical
- Elements: light streaks, circuit abstractions, depth
- Avoid: over-complex details that hurt title readability

## Global Negative Constraints

- No watermark
- No random English slogan unless requested
- No fake UI screenshot blocks
- No dense tiny text
